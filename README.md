# 📖 About

**ReinforceAI** is an AI-assisted speech therapy and smart reinforcement platform developed to improve motivation, fluency, and therapy adherence for speech learners and children with Autism Spectrum Disorder (ASD).

Instead of static rewards, **ReinforceAI** introduces **adaptive positive reinforcement** by unlocking engaging educational reward videos as speech activities, flashcards, and matching games are completed.

---

# ✨ Key Features

- **🔑 Google Authentication**: Seamless "Continue with Google" popup login via Firebase Authentication alongside standard password authentication.
- **🎤 Speech Practice**: Interactive pronunciation, fluency, and speech exercise tracking with real-time feedback.
- **🖼 Interactive Flashcards & Matching Games**: Gamified memory matching and visual vocabulary development.
- **🎥 Adaptive Reward Videos**: Intelligent reward recommendations dynamically tuned to learner preferences.
- **📊 Parent & Therapist Dashboard**: Clinical progress analytics, printable reports, and motivation tracking.

---

# 🤖 AI Features

- **Adaptive Reinforcement Engine**: Recommends high-engagement rewards based on child activity completion.
- **Personalized Schedules**: Generates dynamic daily therapy goals.
- **Motivation Index**: Real-time engagement score calculation based on consistency and accuracy.

# 🛠 Technology Stack

### Frontend & Core
- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4
- **Authentication**: Firebase Authentication (Google Sign-In + Email/Password)
- **Deployment**: Vercel

# 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/muralisaiharish-dotcom/theraboost-ai.git

# Move into project directory
cd theraboost-ai

# Install dependencies
pnpm install

# Run local development server
pnpm dev

# Build for production
pnpm build
```
